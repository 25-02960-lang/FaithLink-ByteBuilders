<h1 align="center">FaithLink</h1>

<p align="center">
  A console-based, choice-driven romance story game created in Java.
</p>

<hr>

<h2>About the Project</h2>

<p>
FaithLink is a gender-friendly interactive story game developed using
Object-Oriented Programming (OOP) principles. The player makes choices,
builds relationship points with characters, and reaches different endings.
</p>

<h2>Features</h2>

<ul>
  <li>Player name input</li>
  <li>Console-based menu and story choices</li>
  <li>Two romance characters: Aira and Liana</li>
  <li>Relationship point system</li>
  <li>Multiple endings: Romance, Friendship, or Independent</li>
  <li>Input validation for incorrect choices</li>
  <li>Replay and exit options</li>
</ul>

<h2>How to Run</h2>

<ol>
  <li>Download or clone this repository.</li>
  <li>Open the project folder in Visual Studio Code.</li>
  <li>Double-click <code>run-faithlink.bat</code>.</li>
  <li>The FaithLink console game will open in a separate window.</li>
</ol>
